## Context

当前系统允许用户创建同名任务，这在批量管理时会造成混淆。此外，批量执行功能在记录日志时存在变量引用错误，导致显示undefined。

## Goals / Non-Goals

**Goals:**
- 实现任务名称重复检测与确认机制
- 修复批量执行日志显示undefined的问题

**Non-Goals:**
- 不修改任务数据结构
- 不添加复杂的验证规则（仅检查名称重复）

## Decisions

### 决策1: 重复检查时机
在点击"保存"按钮时进行异步检查，若发现重复则弹出确认对话框。

**替代方案:** 
- 实时检查（输入时）- 过于频繁，用户体验不佳
- 服务端验证 - 增加不必要的IPC调用复杂度

### 决策2: 对话框实现
使用原生Electron对话框（ipcRenderer.invoke）而非自定义HTML模态框，保持一致性。

### 决策3: 日志修复方案
检查`executeAllTasks`函数中任务对象的属性访问，确保使用`task.name`而非未定义的变量。

## Risks / Trade-offs

- [Risk] 用户可能因频繁确认而感到困扰 → 仅在名称真正重复时弹出确认
- [Risk] 日志修复可能遗漏其他类似问题 → 全面检查所有日志输出点
