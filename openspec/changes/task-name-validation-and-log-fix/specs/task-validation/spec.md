## ADDED Requirements

### Requirement: 任务名称唯一性检查
系统必须在保存任务前检查任务名称是否已存在。

#### Scenario: 创建任务时名称重复
- **WHEN** 用户尝试保存一个名称已存在的任务
- **THEN** 系统显示确认对话框询问是否继续
- **AND** 对话框显示信息"任务名称'xxx'已存在，是否继续保存？"

#### Scenario: 用户确认保存重复名称
- **GIVEN** 系统检测到任务名称重复
- **WHEN** 用户点击确认对话框的"确定"按钮
- **THEN** 系统继续保存任务

#### Scenario: 用户取消保存重复名称
- **GIVEN** 系统检测到任务名称重复
- **WHEN** 用户点击确认对话框的"取消"按钮
- **THEN** 系统取消保存操作并关闭对话框

#### Scenario: 编辑任务时名称未变更
- **GIVEN** 用户正在编辑现有任务
- **WHEN** 任务名称与原始名称相同
- **THEN** 系统不触发重复检查

### Requirement: 批量执行日志正确显示
系统在执行批量任务时必须正确记录每个任务的名称。

#### Scenario: 批量执行任务
- **WHEN** 系统批量执行多个任务
- **THEN** 日志显示"执行：[任务名称]"而非undefined
